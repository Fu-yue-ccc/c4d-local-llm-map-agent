# 运行截图说明

本文件夹用于存放本地运行 Gemma 4 的截图。

## 需要截取的内容

请在你自己的电脑上完成以下操作后截图放入此文件夹：

1. **终端运行截图**：显示 `python sias_map_agent.py` 的运行过程，包含模型名称、生成过程
2. **Ollama 模型列表**：另开终端输入 `ollama list`，显示已安装的 gemma4 模型
3. **地图结果**：浏览器中打开生成的 HTML 地图
4. **设备信息**：任务管理器/活动监视器显示内存占用（可选）

## 截图要求（评审关键）

截图中必须清晰显示：
- 运行的 Gemma 4 模型名称（如 `gemma4:e4b`）
- 运行工具（如 Ollama v0.x.x）
- 设备信息（CPU/GPU、内存、操作系统）
- 模型实际运行中的推理速度（tok/s）

## 建议拼图方式

左边放终端窗口（显示命令+模型名+生成过程），右边放浏览器地图，一张图包含全部信息。
